GEO-04 - canonical mesh/instance contract handoff
=================================================
Status: contract and passive helper slice complete, 2026-07-23.

-------

canonical identity. GEO-04 now has fixed-width WorldKey, MeshKey, InstanceKey,
PrimitiveKey and HistoryOwnerKey value contracts, full-tuple equality and

OWNERSHIP BLOCKERS CARRIED FORWARD
----------------------------------
GEO-05 must provide monotonic render-world registration/teardown and a durable
WorldKey before lifecycle/visible/area observations can emit valid
InstanceKeys. It must also allocate/select the primary logical HistoryOwner.

GEO-06 must provide sourceAssetId/sourceAssetGeneration and immutable topology
signature production before observations can emit valid MeshKeys.

Until those owners exist, passive adapters must report missingDurableWorld or
missingDurableAsset. They must not synthesize canonical-looking IDs from raw
pointers or bare name hashes.

ROLLBACK
--------
The implementation has no live route to disable. Reverting the GEO-04 helper
checkpoint removes the value types and harness. Reverting the preceding
contract checkpoint removes the accepted documentation decisions.
