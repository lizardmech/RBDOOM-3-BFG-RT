GEO-Q15 MATERIAL UNIVERSE AND DIFFUSE DESCRIPTOR CLOSURE
========================================================

Date: 2026-07-30
Scope: post-packet closure of 04_open_questions.txt Q15
Code change: none

QUESTION
--------
Q15 asked whether a material first seen after level load, especially one from
a spawned creature, can enter the live material table. The original
Fatzombie capture answered the identity half but exposed a second failure:

  material  models/monsters/zombie/fatty/fatty
  diffuse   models/monsters/zombie/fatty/fatty_d
  image     present
  result    rejected texture desc

The geometry was valid and the spawned material IDs were admitted. Q15
remained marked partial only because that ordinary diffuse image could not
produce a safe NVRHI descriptor.

CURRENT SOURCE CONTRACT
-----------------------
The intervening material-system repairs now make the descriptor path
generation-aware:

1. Frame and resident-cache hits refresh texture handles from the current
   idImage objects instead of trusting retained raw image/descriptor state.
2. RtSmokeMaterialTextureInfo owns strong NVRHI handles for diffuse, alpha,
   normal, specular, emissive, and sky textures.
3. A material-table cache hit reruns PopulateSmokeMaterialTextureSlots and
   validates the resulting material indexes instead of reusing stale
   descriptor indexes.
4. Descriptor-array population fills the active table safely and resets the
   table with scene replacement, preventing an old slot from surviving a
   smaller/new material set.
5. Resident material-ID hydration resolves missing IDs through the declaration
   universe and refreshes existing handle state before table construction.

The key historical implementation checkpoints are:

  654f44f85 Avoid stale image pointers in material table
  695fec408 Rebuild material descriptors on cache hits
  243434225 Harden smoke texture descriptor residency

These are material-system fixes, not changes to geometry identity.

DECISION
--------
Q15 is resolved.

The original spawn capture proves that mid-level-first-seen IDs enter the
material universe. The current source audit and runtime census prove that the
specific ordinary diffuse descriptor defect that kept Q15 partial has been
repaired. No geometry or material code change is required for closure.

This decision does not require every material to own a diffuse texture. Sky,
absorbing black, stage-driven PDA effects, and glass are intentionally
different material contracts. Their specialized sampling, emissive, or
transmission behavior remains owned by the material/lighting lanes and must
not be reopened as a geometry-universe identity failure.

REOPEN CONDITIONS
-----------------
Reopen Q15 only if a newly spawned or newly streamed ordinary textured
material:

  - does not enter the current material-ID universe;
  - has a valid resident diffuse image but no current NVRHI texture handle;
  - receives a stale/wrong descriptor after a table cache hit, portal change,
    map change, image reload, or material-universe growth; or
  - changes geometry/material identity because its table row is reordered.
