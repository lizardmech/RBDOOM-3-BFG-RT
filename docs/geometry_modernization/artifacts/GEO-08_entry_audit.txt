ENTRY CONTRADICTION
-------------------
The old GEO-07/GEO-08 boundary required CPU pre-skinning to disappear before
GEO-08 while also forbidding GEO-07 from routing the new output through a BLAS.
The live renderer cannot satisfy both statements:

  BuildSmokeSurfaceVertexFromSource
    -> CPU-skinned world-space dynamicVertexData
    -> smokeDynamicVertexBuffer
    -> merged smokeDynamicBlas
    -> live TLAS traversal.

The accepted GEO-07 mode-1 compute output is a different buffer with no BLAS
consumer. Skipping CPU skinning first would leave bind-pose or invalid data in
the live merged BLAS. D25 therefore moves CPU pre-skin removal to the GEO-08
traversal cutover.

FROZEN FIRST-CUT INPUT CONTRACT
-------------------------------
Per eligible canonical SkinnedSurface InstanceKey:

  vertex buffer/range:
    accepted per-instance PathTraceSmokeVertex output;
    112-byte stride;
    checked output buffer generation, byte offset, count and capacity;

  index buffer/range:
    exact canonical GEO-06 GPU index-pool record;
    checked pool generation, aligned byte offset, count and capacity;
    source indexes remain local to the surface;

  source identity:
    exact SkinnedBindSource/Skinned MeshKey and nonzero source checksum;

  transform:
    identity TLAS transform for the first cut because the accepted compute
    shader writes world-space positions and attributes;

  queue order:
    renderer joint copy -> skin compute -> UAV/AS barrier ->
    per-instance BLAS build/update -> TLAS build;

  update eligibility:
    initial build completed;
    full InstanceKey unchanged;
    mesh/source/index-pool/output storage contract unchanged;
    fixed rebuild cadence not reached;

  retirement:
    exact lifecycle removal, render-def generation replacement, world change,
    or referenced output-buffer generation replacement;
    release requires explicit in-flight completion.

SLICE 1 - PURE STATE CONTRACT
-----------------------------
Added:

  neo/renderer/NVRHI/PathTraceSkinnedBlasState.h
  neo/renderer/NVRHI/PathTraceSkinnedBlasState.cpp
  neo/tests/pathtrace_skinned_blas_state_harness.cpp

PtSkinnedBlasStateTable owns no renderer pointers or GPU handles. It models:

  absent;
  build-pending;
  ready;
  update-pending;
  rebuild-pending;
  failed;
  retiring.

The table:

  keys by the complete InstanceKey, never shared MeshKey;
  validates exact skinned identity and checked source/output ranges;
  requests update only for a stable storage contract;
  requests rebuild for source/output generation or range change;
  requests rebuild after a failed submission;
  applies a fixed observable rebuild cadence;
  invalidates already-pending work when its storage contract changes;
  prevents an explicitly retired entity generation from resurrecting;
  keeps retirement pending until an explicit completion token is acknowledged;
  retires every active record on world replacement.

SLICE 2 - PHYSICAL OUTPUT GENERATION AND LIVE SHADOW OBSERVATION
----------------------------------------------------------------
Implemented:

  one physical PathTraceSkinnedCurrentOutputVertices buffer per nonzero
    PtSkinnedOutputAllocator storage generation;
  exact reuse only when generation, capacity, 112-byte stride, UAV capability,
    and acceleration-structure-build-input capability all match;
  forced physical replacement when the allocator generation changes;
  propagation of the allocator generation through scene-resource commit and
    retired scene packages;
  conservative generation acknowledgement only after the corresponding
    retained package is released and no active/retained package still names
    that generation;
  exact lookup of the GEO-06 canonical source GPU index-pool record;
  live observation of only finalized dispatchedGpu GEO-07 jobs into
    PtSkinnedBlasStateTable.

The observer validates, before creating a state-table candidate:

  full SkinnedSurface InstanceKey and exact identity binding;
  exact SkinnedBindSource/Skinned MeshKey and source checksum;
  checked source index offset/count/end against the live GEO-06 index pool
    generation and capacity;
  checked output offset/count/end against the committed physical buffer
    generation and capacity;
  successful GEO-07 compute dispatch;
  physical UAV and acceleration-structure-build-input flags.

It deliberately calls Observe only. It does not create an NVRHI acceleration
structure and does not call MarkSubmitted. Records therefore remain
build-pending in this shadow slice. No legacy BLAS or TLAS input changed.

SLICE 3 - EXACT GRAPHICS-SUBMISSION COMPLETION
----------------------------------------------
The local NVRHI/Vulkan audit found the required existing primitive:

  IDevice::setEventQuery records the graphics queue's last submitted ID;
  Vulkan implements that ID with its queue tracking timeline semaphore;
  IDevice::pollEventQuery tests the recorded submission ID for completion.

The main renderer now notifies PathTracePrimaryPass immediately after the
frame command list is submitted. Each retired scene package owns an IEventQuery
created before submission and is armed by that notification. Release requires
all of:

  the package's exact event query is armed;
  pollEventQuery reports its recorded graphics submission complete;
  the optional r_pathTracingSceneRetireFrames minimum delay has elapsed.

The cvar is therefore an additional delay, no longer the authority for
completion. A missing query fails safe by retaining the package until reset.
Completed output generations are acknowledged to PtSkinnedOutputAllocator only
after the last active/retained package naming that generation is gone.

r_pathTracingSceneRetireFrames=0:
