GEO-12 rendered static/dynamic attribute survey
================================================

PURPOSE
-------
Close the first survey's ownership gap without changing a geometry format.
This slice measures the final full-fidelity `PathTraceSmokeVertex` values after
dynamic/static material texture-matrix application. It covers the resident
static cache and the explicit drawSurf-mirror dynamic fallback at the point
actually consumed by BLAS construction and hit shaders.

This is measurement only. No encoding, eligibility predicate, fallback route,
descriptor, shader ABI, BLAS stride, or default production behavior changes.

VALIDATED OWNER AND IDENTITY CONTRACT
-------------------------------------
Static:

- `RtSmokePersistentStaticSurfaceRecord::currentRange` is the exact resident
  vertex/index/triangle range.
- `bucketSurfaceKey` joins to `RtPathTraceSceneUniverseSurface::key`.
- `key` joins to `legacyDrawSurfKey` as a compatibility fallback.
- The join preserves model/material name, class/material IDs, surface index,
  entity, and portal area.

Dynamic:

- The drawSurf mirror builds one per-class bucket then concatenates buckets.
- Triangle instance data is entity-level and cannot recover unique surface
  ranges after merge.
- GEO-12 therefore adds `RtSmokeCapturedSurfaceRecord`, an observation-only CPU
  ledger created beside `RtSmokeSkinnedSurfaceRecord` only while the one-shot
  survey CVar is nonzero.
- It records the local per-surface range and immutable string/ID diagnostics;
  the existing bucket merge adds the final base offsets.
- The ledger is not retained, uploaded, or used by routing.

The live scene-source-3 path has one mirror capture call site. Legacy
`CaptureDoomSurfacesForSmokeTest` is deliberately not assigned invented
per-surface ranges. A survey run on that producer reports zero dynamic ledger
records rather than implying coverage it does not own.

MEASUREMENT CONTRACT
--------------------
The new one-shot CVar is:

  r_pathTracingGeometryRenderedAttributeSurveyDump <1-based-page>

Each page emits at most 32 rows. The aggregate is repeated and includes:

- record totals, static/dynamic split, invalid-range count, and class census;
- full rendered position range;
- diffuse UV (`texCoord.xy`) and normal-map UV (`texCoord.zw`) ranges;
- separate half conversion overflow, underflow, max absolute error, and max
  relative error for both UV pairs;
- non-finite position, both UV pairs, basis, and color counts;
- oct16 normal/tangent maximum angular error;
- stored-versus-derived bitangent error and invalid count;
- UNORM8 exactness for both color streams;
- independent candidate savings against the current 112-byte ABI.

Rows preserve domain, identity, class/material IDs, entity/model-surface/area,
vertex count, both UV ranges, half failures, basis errors, and model/material
names.

INTERPRETATION
--------------
1. The final rendered seam is now measurable without a route or ABI change.
2. Half UV is not admitted. The zero error is expected for many values already
   sourced through half-precision draw vertices, and this one portal-resident
   frame does not prove all texture-matrix scales or wide/repeating materials.
3. Any UV eligibility predicate must test both `xy` and `zw`. Slice 1 did not
   contain the second pair; this frame proves its range differs materially.
4. Derived bitangent is not exact in rendered space even in this clean frame.
   A later candidate needs a declared angular threshold and surface fallback.
5. UNORM8 color/color2 remains a strong candidate, but this prepared-save
   capture alone does not select either stream.

ORDERED CONTINUATION
--------------------
1. Select canonical `color` alone as the first lossless candidate. Do not also
   encode `color2`.
2. Keep the rendered 112-byte vertex, transport packet, GPU pool, BLAS, and
   shader ABI full fidelity.
3. Store a 68-byte canonical attribute only when every `color` component is
   finite, in [0,1], and round-trips through UNORM8 within 1e-7. Otherwise
   retain the 80-byte record with a named fallback reason.
4. Prove representation-independent checksum, exact decoded bytes, unchanged
   transport budget, and 12 saved retained bytes per eligible vertex in pure
   harnesses.
5. Run default-off/default-on map-reload A/B using the canonical survey dump.
   Only after numeric/runtime acceptance consider extending packed storage
   across transport or into the GPU ABI.
