GEO-09 entry audit - skinned temporal/material/emissive promotion
================================================================
Status: step 1 consumer inventory and CPU contract audit accepted, 2026-07-26.

SCOPE
-----
This entry slice is behavior-neutral. It inventories the live skinned
consumer funnel and adds a one-shot validator. It does not change traversal,
materials, motion, emissive inventories, DI/GI/RR behavior, or shaders.

LIVE PRODUCER AND HIT ROUTE
---------------------------
The accepted GEO-08 route already provides:

  CPU route:
    PtSkinnedHitRouteRecord
      full canonical InstanceKey and MeshKey
      collision-checked 64-bit instance hash
      source index, current output, and previous-position ranges
      source/output generations and source-local triangle range

    PtSkinnedHitRouteTriangle
      source-local primitive index
      optional legacy merged-dynamic primitive index
      material ID and material-table index
      triangle class/flags
      canonical primitive identity
      canonical emissive identity

  GPU route:
    PathTraceSkinnedHitRouteGpuRecord at t18
    PathTraceSkinnedHitRouteGpuTriangle at t19
    immutable source indexes at t28
    current world-space skinned output at t29
    previous world-space positions at t32

  AS route:
    one updateable BLAS per eligible skinned surface
    identity-transform TLAS descriptors
    mask 0x02 for active descriptors
    SBT contributions 2/3 for skinned primary/shadow hits

CONSUMER INVENTORY
------------------
Primary/general PT:

  PathTraceSkinnedHitRoute.hlsli
  pathtrace_primary_surface_producer.rt.hlsl
  pathtrace_smoke.rt.hlsl

These recover source-local current vertex attributes, material ID/index, and
triangle class. The primary payload carries instance, primitive, material,
class, current world position, barycentrics, UV, normals, and tangent data.

Temporal/motion:

  pathtrace_smoke_rab_motion_supplier.hlsli
  PathTracePrimarySurface.hlsli

The motion supplier uses the route's previousPositionOffset and the same
source-local indexes. Current and previous positions are already world-space.
Primary-surface history packs the resulting instance/primitive/material/class
and previous object position for ReSTIR/RR reprojection.

DI/GI/debug:

  cleanroom_rtxdi/pathtrace_clean_rtxdi_di_hit_surface_adapter.hlsli
  cleanroom_rtxdi/pathtrace_clean_rtxdi_di_surface_adapter.hlsli
  cleanroom_rtxdi/pathtrace_clean_rtxdi_di_skinned_hits.rt.hlsl
  remix_restir_gi/pathtrace_clean_restir_gi_skinned_hits.rt.hlsl
  pathtrace_regir_debug.rt.hlsl
  pathtrace_nee_cache_debug.rt.hlsl

These contain explicit skinned route branches. Their algorithm behavior stays
outside GEO-09; later steps validate only geometry/material inputs.

Materials:

  PathTraceMaterialUniverse and PathTraceDynamicMaterialState own the material
  table and runtime texture/state records. Canonical skinned triangles carry
  both material ID and the current frame's material-table index.

Emissives and the concrete remaining mismatch:

  BuildSmokeEmissiveTriangleInventory walks captured static/dynamic payloads.
  AppendSmokeEmissiveInventoryForGeometry explicitly skips
  RT_SMOKE_SURFACE_CLASS_SKINNED_DEFORMED.

Canonical skinned triangles therefore contribute no
PathTraceSmokeEmissiveTriangle records, emissive distribution entries, or
unified-light records. This matches the legacy skip but does not satisfy
GEO-09/Q17. The replacement must consume mesh-local primitives, per-instance
identity, and current GPU-skinned positions without restoring CPU skinning.

FIRST ACCEPTED VALIDATOR
------------------------
New default-zero cvar:

  r_pathTracingGeometrySkinnedConsumerAudit 1

The one-shot validates two independent views:

  live:
    exact source-only CPU route, GPU upload, and accepted TLAS plan.

  shadow:
    same frame and surface set rebuilt diagnostically with retained legacy
    merged-dynamic offsets. It never enters a TLAS or GPU buffer.

Both views validate route/triangle counts, CPU/GPU field equality, current and
previous bounds, material-table identity, source-local primitive identity,
canonical emissive identity, and identity collisions. The shadow additionally
validates every mapped triangle's material ID/index and class/flags against
the legacy arrays. Injected harness failures cover material-table,
legacy-class, motion-range, GPU-upload, and TLAS-route mismatches.

SAME-RAY PRIMARY-HIT AUDIT
--------------------------
Step 2/3 adds default-zero:

  r_pathTracingGeometrySkinnedHitAudit 1
  r_pathTracingDebugMode 58

Mode 58 samples one adjacent legacy/canonical pixel pair per 8x8 block. Both
pixels reconstruct the exact same ray at the pair midpoint. The legacy pixel
traces mask 0x01; the canonical pixel traces mask 0x02. Numeric payloads are
compacted into the existing primary-surface history buffer, so no shader ABI,
descriptor, or pipeline binding changes were required. At 2560x1440 the audit
copies 57,600 pairs / 20,275,200 bytes rather than the full 648,806,400-byte
history.

Each canonical skinned hit is mapped through InstanceID and source-local
PrimitiveIndex to the independent legacy-backed shadow. Static geometry that
occludes the canonical-only ray is counted separately. Only unobstructed
exact-primitive pairs enter tuple comparison. The compared fields are:

  hit T and world position;
  geometric and shading normal;
  tangent and bitangent;
  UV and normal-map UV;
  barycentrics;
  material ID, table index, subtype, and surface class;
  triangle class/flags.

Declared tolerances:

  tuple/position/geometric/UV/barycentric: 1e-3 max component
  normalized shading/tangent/bitangent:    1e-2 max component

The wider basis tolerance covers independent CPU/GPU weighted normalization.
The accepted run's worst basis delta is 0.00529411435; its position and
barycentric maxima are 0.000305175781 and 0.000289946795.

FIRST MISMATCH FOUND AND FIXED
------------------------------
geometry_geo130_auto proved 5,264 canonical skinned samples but every exact
pair disagreed in triangle flags. The source-only producer kept only surface
class 2 and dropped RT_SMOKE_TRIANGLE_EMISSIVE_STAGE_OFF (0x00040000), while
legacy triangles carried 0x00040002. `RtSmokeSkinnedSurfaceRecord` now captures
the already-evaluated per-surface class/flag tuple, and source-only route
metadata consumes it without consulting legacy merged offsets.
