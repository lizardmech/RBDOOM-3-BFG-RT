AUDIT CONTRACT REPAIRS
----------------------
The bounded matrix exposed three diagnostic-only ordering assumptions.

First, consumer and hit audits already retained one CPU-skinned frame so their
independent legacy shadow remained available after capture split. The
emissive audit did not, so its GPU-output check compared against source-local
or zero placeholder vertices. The emissive one-shot now requests the same CPU
reference retention.

Second, a command may become visible to the backend after the corresponding
frontend capture has already omitted CPU geometry, and the first retained
frame may not yet have an exact retained previous-position range. The emissive
one-shot now latches its request once per scene build and consumes value one
only after every routed instance has exact current and previous CPU ranges.

Third, retaining CPU geometry can change frame-local material slots. The
cached source-only route is now rebuilt against the current frame's material
table for all CPU-reference audit frames, not only ordinary omitted-capture
frames. Validation material lookup also resolves the stable material ID to the
current table index. This removes stale-index failures without weakening the
production route: audit-retained routes remain excluded from traversal.

Finally, validation-only emissive publication is permitted while that
CPU-reference frame intentionally keeps the per-instance BLAS out of the
production TLAS. The CVar defaults to zero, the injected set remains capped at
24 records, and output reports
`defaultProductionBehaviorChanged=0`.
