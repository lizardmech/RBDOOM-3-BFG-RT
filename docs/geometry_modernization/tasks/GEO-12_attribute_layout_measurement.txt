GEO-12 - Measure and introduce safe attribute storage reductions
================================================================

GOAL
----
Measure actual asset ranges and shader sensitivity, then reduce geometry memory
only where numeric/full-scene comparisons prove the chosen encoding safe.

PRECONDITIONS
-------------
- Phase D geometry routes are functionally correct at full fidelity.
- Full-fidelity storage remains the fallback.

FILES TO AUDIT FIRST
--------------------
  neo/renderer/NVRHI/PathTraceGeometry.h/.cpp
  neo/renderer/NVRHI/PathTraceSceneCapture.cpp/.h
  neo/renderer/NVRHI/PathTraceGeometryUniverse.cpp/.h
  neo/renderer/NVRHI/PathTracePrimarySurface.h
  neo/shaders/builtin/pathtracing/PathTracePrimarySurface.hlsli
  neo/shaders/builtin/pathtracing/pathtrace_skinning.cs.hlsl

STEPS
-----
1. Inventory all CPU and shader consumers of position, previous position,
   normal, tangent/handedness, UV, color, weights, and joint indices.
2. Add a bounded asset survey reporting per mesh: AABB/range, UV min/max and
   required precision, normal/tangent error sensitivity, joint/weight ranges,
   non-finite values, and candidate encoding eligibility.
3. Include ordinary world surfaces, large-coordinate/static surfaces, player,
   zombies, Fatzombie, wide/repeating UV materials, decals, emissives, and the
   explicit small-dynamic fallback classes.
4. Keep positions in a separate mutable stream where skinning/BLAS requires it.
   Evaluate deriving normal/tangent in skinning versus writing them based on
   measured bandwidth and dispatch time.
5. Implement one encoding at a time behind a default-off gate. Define decode ABI
   and CPU static asserts/preprocessed HLSL review before runtime use.
6. Compare decoded vertex attributes numerically against full fidelity. Then
   compare primary hit, material UV, normal mapping, motion, and emissive
   triangle reconstruction in the same frames.
7. Route ineligible/wide-UV/out-of-range meshes to explicit full-fidelity
   records with reason counters. Never clamp silently.
8. Measure source/mutable buffer bytes, upload bytes, skinning time, BLAS time,
   and frame time on identical geometry.
9. Accept an encoding only if memory/bandwidth savings are material and all
   declared error thresholds pass. Otherwise retain full fidelity and record the
   rejected candidate.

GUARDRAILS
----------
- No invented universal UV range.
- No visual-only acceptance for attribute error.
- Do not combine multiple encodings in one experiment.

DONE WHEN
---------
The selected layout has a documented eligibility predicate, error thresholds,
fallback, ABI proof, scene comparisons, and measured savings. Rejected
compressions remain rejected evidence, not hidden assumptions.

CHECKPOINT
----------
  pt geometry GEO-12: validate <attribute> storage encoding

ENTRY AUDIT AND MEASUREMENT SLICE 1
-----------------------------------
The current renderer does not have one universal vertex-storage seam.
`PathTraceSmokeVertex` is a 112-byte rendered ABI shared by BLAS builds, every
RT hit family, emissive reconstruction, and readback. It is explicitly not the
first compression target.

The full-fidelity canonical source already separates float3 position (12 bytes)
from immutable attributes (80 bytes). The first slice adds a pure CPU,
observation-only survey over those value-owned records. It measures numeric
ranges and independent half-UV, oct16 basis, derived-bitangent, UNORM8 color,
joint, and weight evidence without changing a source record or GPU ABI. The
paged one-shot command is:

  r_pathTracingGeometryAttributeSurveyDump 1

Each page contains at most 32 per-mesh rows and repeats the aggregate. Candidate
savings are reported separately and are not an accepted combined layout.

This source registry currently covers rigid registered models and skinned bind
sources only. Static world, generated geometry, particles, decals, and other
dynamic fallbacks require a second read-only survey at their capture/resident
source owners before Q1 or any encoding can be resolved. No eligibility
threshold or encoding is selected by Slice 1.

Detailed evidence and the ordered continuation are in:

RENDERED STATIC/DYNAMIC SURVEY SLICE 2
--------------------------------------
The second observation-only survey closes the live rendered-capture ownership
gap for scene source 3. Static resident ranges join the persistent geometry
record to scene-universe identity. A new frame-local diagnostic ledger records
each emitted dynamic fallback's local range and receives its final base during
the existing bucket merge only when the survey is requested. It is never
uploaded or used for routing.

The paged command is:

  r_pathTracingGeometryRenderedAttributeSurveyDump <1-based-page>

It runs after material texture matrices are applied and measures the full
112-byte rendered vertex, including diffuse `texCoord.xy` and normal-map
`texCoord.zw` separately.

Prepared-save evidence covers 533 records: 474 static-world and 59 dynamic
fallbacks (56 rigid, two skinned, one particle), 26,296 vertices, and zero
invalid ranges. Both UV pairs have zero half failures in this frame, but their
ranges differ: diffuse reaches (-35.46875,-20)..(35,20.5), while normal-map UV
reaches (-35.46875,-72)..(35,72). This makes a both-pairs predicate mandatory
and does not admit half storage. Rendered derived-bitangent error reaches
0.306467 degrees even without an invalid record.

Detailed contract, logs, interpretation, and ordered coverage continuation:

  ../artifacts/GEO-12_rendered_capture_survey.txt

Representative coverage is now complete in `geometry_geo12_coverage.log`:
589 static-world, 21 skinned, and five particle records, including zfat and
normal-map UV down to -96, with zero invalid ranges. Half UV has nonzero error;
four bitangents are not derivable and valid reconstruction reaches 10.6426821
degrees. Both color streams remain UNORM8-exact over all 160,240 components.

ENCODING SLICE 3
----------------
`color` alone is selected for the first default-off canonical storage A/B.
Eligible records replace the 80-byte immutable attribute with an exactly
68-byte form, saving 12 retained CPU bytes per vertex. The predicate is
record-atomic: all components must be finite, in [0,1], and round-trip through
UNORM8 within 1e-7. Non-finite, out-of-range, and non-exact records keep full
fidelity with named counters.

The source checksum remains over logical full-fidelity input. Transport and
the canonical GPU pool stay decoded at the existing 80-byte ABI, so this slice
adds no shader, descriptor, SBT, BLAS-stride, or packet-record change. The
default-off capture-time gate is:

  r_pathTracingGeometrySourceColorUnorm8 0

Reload the map after changing it for a complete A/B. Detailed decision,
contracts, exclusions, and runtime acceptance:

  ../artifacts/GEO-12_first_encoding_selection.txt

Pure registry/transport/survey harnesses and the full Vulkan release build
pass. No shader was edited and all SPIR-V remained up to date. The deployed
16,070,656-byte executable is byte-identical to the build with SHA-256:

  9F72A28F1C012351194FF2A1279A86B2742A2281CA3255D9BAEA5F450E09182B

Runtime off/on evidence remains the acceptance gate; this checkpoint does not
promote the CVar.

RUNTIME A/B ACCEPTANCE
----------------------
`geometry_geo12_color_off.log` proves gate-off storage is 0/982 packed/full
with zero saved bytes. Its dump occurred before six late skinned records were
observed. `geometry_geo12_color_on.log` reaches the complete 988-record,
64,986-vertex inventory: all 988 records pack, all three fallback counters are
zero, and canonical attribute retention falls from 5,198,880 to 4,419,048
bytes. The exact saving is 779,832 bytes, or 15 percent of this attribute
stream.

The complete enabled decoded aggregate matches the complete earlier
full-fidelity `geometry_geo12d.log` aggregate in every reported numeric field.
There are no source import/checksum/retained/range/GPU-pool rejections, device
losses, or abnormal shutdowns in either new log.

The color-only encoding is accepted. The CVar remains default off so that
promotion stays an explicit later change rather than being hidden in the
measurement checkpoint.
