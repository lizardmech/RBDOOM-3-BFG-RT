GEO-12 - Measure and introduce safe attribute storage reductions
================================================================

GOAL
----
Measure actual asset ranges and shader sensitivity, then reduce geometry memory
only where numeric/full-scene comparisons prove the chosen encoding safe.

PRECONDITIONS
-------------
- Phase D geometry routes are functionally correct at full fidelity.
- Full-fidelity storage remains the fallback.

FILES TO AUDIT FIRST
--------------------
  neo/renderer/NVRHI/PathTraceGeometry.h/.cpp
  neo/renderer/NVRHI/PathTraceSceneCapture.cpp/.h
  neo/renderer/NVRHI/PathTraceGeometryUniverse.cpp/.h
  neo/renderer/NVRHI/PathTracePrimarySurface.h
  neo/shaders/builtin/pathtracing/PathTracePrimarySurface.hlsli
  neo/shaders/builtin/pathtracing/pathtrace_skinning.cs.hlsl

STEPS
-----
1. Inventory all CPU and shader consumers of position, previous position,
   normal, tangent/handedness, UV, color, weights, and joint indices.
2. Add a bounded asset survey reporting per mesh: AABB/range, UV min/max and
   required precision, normal/tangent error sensitivity, joint/weight ranges,
   non-finite values, and candidate encoding eligibility.
3. Include ordinary world surfaces, large-coordinate/static surfaces, player,
   zombies, Fatzombie, wide/repeating UV materials, decals, emissives, and the
   explicit small-dynamic fallback classes.
4. Keep positions in a separate mutable stream where skinning/BLAS requires it.
   Evaluate deriving normal/tangent in skinning versus writing them based on
   measured bandwidth and dispatch time.
5. Implement one encoding at a time behind a default-off gate. Define decode ABI
   and CPU static asserts/preprocessed HLSL review before runtime use.
6. Compare decoded vertex attributes numerically against full fidelity. Then
   compare primary hit, material UV, normal mapping, motion, and emissive
   triangle reconstruction in the same frames.
7. Route ineligible/wide-UV/out-of-range meshes to explicit full-fidelity
   records with reason counters. Never clamp silently.
8. Measure source/mutable buffer bytes, upload bytes, skinning time, BLAS time,
   and frame time on identical geometry.
9. Accept an encoding only if memory/bandwidth savings are material and all
   declared error thresholds pass. Otherwise retain full fidelity and record the
   rejected candidate.

GUARDRAILS
----------
- No invented universal UV range.
- No visual-only acceptance for attribute error.
- Do not combine multiple encodings in one experiment.

DONE WHEN
---------
The selected layout has a documented eligibility predicate, error thresholds,
fallback, ABI proof, scene comparisons, and measured savings. Rejected
compressions remain rejected evidence, not hidden assumptions.

CHECKPOINT
----------
  pt geometry GEO-12: validate <attribute> storage encoding

ENTRY AUDIT AND MEASUREMENT SLICE 1
-----------------------------------
The current renderer does not have one universal vertex-storage seam.
`PathTraceSmokeVertex` is a 112-byte rendered ABI shared by BLAS builds, every
RT hit family, emissive reconstruction, and readback. It is explicitly not the
first compression target.

The full-fidelity canonical source already separates float3 position (12 bytes)
from immutable attributes (80 bytes). The first slice adds a pure CPU,
observation-only survey over those value-owned records. It measures numeric
ranges and independent half-UV, oct16 basis, derived-bitangent, UNORM8 color,
joint, and weight evidence without changing a source record or GPU ABI. The
paged one-shot command is:

  r_pathTracingGeometryAttributeSurveyDump 1

Each page contains at most 32 per-mesh rows and repeats the aggregate. Candidate
savings are reported separately and are not an accepted combined layout.

This source registry currently covers rigid registered models and skinned bind
sources only. Static world, generated geometry, particles, decals, and other
dynamic fallbacks require a second read-only survey at their capture/resident
source owners before Q1 or any encoding can be resolved. No eligibility
threshold or encoding is selected by Slice 1.

Final-build `geometry_geo12d.log` captures 988 records and 64,986 vertices. It
reports no
non-finite components, UV range (-64.5,-28.5)..(64.5,38.75), exact half
round-trip for the stored source UVs, oct16 maximum normal/tangent error
0.039565/0.034264 degrees, and two explicit invalid derived-bitangent vertices.
Both color streams are UNORM8-exact for all 259,944 components apiece. The
19,581 skinned vertices have zero nonintegral/out-of-byte joints, joint range
0..79, finite weights in 0..1, and sums in 1..1.00000012.

`geometry_geo12c.log` proves pages 30/31 emit all 42 skinned per-mesh rows,
including both 3,050-vertex `zfat.md5mesh` surfaces. Both automated runs shut
down normally without device loss. These results remain domain-limited
measurement, not encoding acceptance.
