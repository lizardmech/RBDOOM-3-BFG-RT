Frozen receiver predicate:

  face-forward card/receiver plane dot >= 0.95

    [-0.05, 1.85]
  route supplies explicit accepted domain and identity evidence
  receiver is opaque and does not advertise PATH_TRANSMISSION

Frozen occurrence/winner key, lexicographically smallest on metric ties:

  instanceId
  primitiveIndex
  materialIndex
  barycentricXBits
  barycentricYBits

The barycentric words are full finite saturated positive-float bit patterns.
They are not packed, truncated, or hashed. A diagnostic hash is carried only to
prove deliberate hash collisions cannot affect authoritative winner selection.
An exact same-key malformed data collision uses a deterministic lexicographic
comparison of the entire sanitized contributor payload as a final safety rule.

The reducer reads no resources and uses no traversal intrinsics, random values,
derivatives, bindings, payloads, output UAVs, CVars, or screen-space state.
Coverage and height are independent scalar maxima. Winner data always comes
from one whole sanitized contributor. Invalid/nonfinite coverage, height, RGB,
and zero coverage are identity. Finite coverage/height clamp to [0,1]. Optical
parameter NaN/Inf values use the LPD-02 defaults/clamps.

Application is guarded by alreadyApplied. It computes exactly:

  Tunit = clamp(referenceTransmittance * decalRgb, 1/1024, 1)
  d = clamp(opticalDepthScale * height, 0, 8)
  T = exp(log(Tunit) * d)
  Fc = ((ior-1)/(ior+1))^2
  Acoat = receiverAlbedo * T
  Fcoat = Fc + (1-Fc)^2 * receiverF0
  effective fields = coverage lerp(dry, coated)

No second Fresnel multiplier, transmission/refraction ray, normal application,
or receiver position/depth/identity/geometry-normal/motion mutation exists.
Darkest allowed film remains applied and finite; no albedo eligibility floor is
introduced.

The primary producer includes the reducer only as an unused compile probe. `rg`
finds reducer/application/receiver calls only at their definitions. No live
beauty or traversal path invokes the reducer in LPD-03.
