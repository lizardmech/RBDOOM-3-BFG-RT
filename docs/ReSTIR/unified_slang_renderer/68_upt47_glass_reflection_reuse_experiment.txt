68_upt47_glass_reflection_reuse_experiment.txt
================================================

Status
------

Vulkan implementation and offline validation complete on 2026-08-14.
Runtime image-quality and timing acceptance is pending.  This is an opt-in
experiment and does not replace the accepted deterministic UPT46 reflection.

Question
--------

Can glass use a low-resolution direct-light reservoir followed by the accepted
UPT temporal and spatial algorithms, then blend that result over the stable
one-ray PSR reflection before DLSS-RR?

Implemented domain
------------------

`r_pathTracingUnifiedPtGlassReflectionReuse 1` creates a private reflection
domain owned by `PathTraceUnifiedPtState`:

* G1 traces the existing deterministic full-resolution reflected ray;
* one even/even pixel per 2x2 block publishes a 48-byte reflected receiver;
* a 32-byte sidecar keeps the front-pane previous-position reprojection anchor
  and pane depth, while target evaluation remains at the reflected hit;
* a child UPT state owns two half-resolution receiver pages, two reservoir
  pages, D0, T0, S0 and R0;
* D0/T0/S0 are direct-only and analytic-only for this first isolation test;
  reflected emissive endpoints remain receiver self-emission, but emissive RIS
  is deliberately excluded;
* T0 and S0 use compact48 specializations of the accepted direct reuse math;
* G2 bilinearly reconstructs the half-resolution result and multiplies it by
  the pane reflection weight;
* invalid/unsupported child pixels retain the original deterministic RGB
  reflection; exact mirrors stay entirely on the full-resolution path;
* the final reflected HDR contribution is duplicated into the DLSS-RR
  specular guide at the same brightness as beauty.

The child domain never aliases the main UPT receiver history or reservoir
pages.  It adds no per-frame full-buffer clear.  Disabling the cvar destroys
the private child resources and restores the prior UPT46/G2 behavior.

Why compact48
-------------

Compact32 is camera-relative and cannot independently preserve the exact
reflected hit position, bent-path view direction and pane reprojection anchor.
Compact48 stores the hit position and view direction exactly enough for D0
target evaluation; its ordinary history sidecar is specialized so T0 projects
the pane rather than pretending that the reflected terminal is camera-visible.

Runtime A/B
-----------

Use the normal accepted glass configuration, then toggle only:

    r_pathTracingUnifiedPtGlassReflectionReuse 0
    r_pathTracingUnifiedPtGlassReflectionReuse 1

The child resolution is independently selectable:

    r_pathTracingUnifiedPtGlassReflectionReuseResolution 50
    r_pathTracingUnifiedPtGlassReflectionReuseResolution 100

Values below 75 select 50% per axis; values 75 or greater select 100%. A
runtime change reallocates only the private reflection child, invalidates its
private history and logs requested/effective resolution plus receiver size.
G1 publication and G2 reconstruction both consume the effective mode, so full
resolution is a real one-receiver-per-pixel path rather than a larger sparse
half-resolution page. The Vulkan build and UPT45/UPT46 `spirv-val` pass;
deployed hashes are EXE
`CA63393022DFF68F8DEA00E1E4D0B7A4799C8124C8D81C6F67ECF3C3CDA6E81F`,
UPT45 `BD4E7C954CC3D872BD37DBAA8B8D431DC0347086F4962E107A62AFBD5E851AD8`
and both UPT46 light-layout variants
`D95D732416B2D67EFA0E22EAF2760F9F1025FBC434CCE46045FC35725E3EE22E`.

Acceptance observations:

1. no startup descriptor mismatch or child-dispatch failure log;
2. glass reflections gain stable direct-light shading without reverting to
   the earlier full-resolution noisy mini-renderer;
3. emissive shapes remain present through self-emission;
4. no 2x2 block boundaries, pane-edge leaks or reflected-history swimming;
5. DLSS-RR retains the same reflection brightness as noisy color;
6. G1 plus child D0/T0/S0 cost is competitive with the deterministic UPT46
   fallback and materially below the rejected full reflection estimator.

Build proof
-----------

`cmake --build --preset win64-pt-dev-release` passes.  `spirv-val` passes for
the six deployed Vulkan artifacts: UPT05 reflection resolve, UPT07 reflection
temporal, UPT09 reflection spatial, UPT45 compose, and both UPT46 light-layout
variants.  No DX12 shader was compiled.

RR classification correction, 2026-08-14
-----------------------------------------

The first runtime image was raw ReSTIR under DLSS-RR and diagnostics classified
the reflection as diffuse. Two ordering/ownership errors caused it. G1 blended
the reflected terminal's diffuse albedo into the pane's diffuse guide even
though the entire bent camera path is specular. G2 initially wrote reflected
radiance to the specular guide, but its later distortion-consistent guide copy
could overwrite that value with the transmitted receiver's material F0.

When reflection reuse is enabled, G1 now leaves the canonical behind-pane
diffuse guide untouched. G2 records the exact final reflection contribution,
performs any distortion guide remap, and then writes that HDR contribution to
the specular guide as the final operation. The value is therefore identical to
the term added to combined noisy color and cannot be replaced downstream by
the transmitted surface. The targeted UPT45/UPT46 Vulkan rebuild and
`spirv-val` pass; runtime DLSS-RR acceptance remains pending.

Reflection-history correction, 2026-08-14
-----------------------------------------

The reflection child exists to produce an already stabilized direct-light
estimate before G2 and DLSS-RR. DLSS-RR is not the glass denoiser. The first
runtime image remained raw because the compact48 sidecar stored the front-pane
reprojection anchor but marked it valid only when the pane already carried an
object-motion previous-position flag. Static glass therefore reprojected the
off-camera reflected hit itself, which is not the inverse of the mirror path,
and T0 rejected the prior reflected receiver.

UPT46 now always marks the stored pane anchor as the reflection receiver's
previous position. Moving panes still use their true prior pane position;
static panes use their unchanged world position. The private reflection
history gate now depends only on the child allocation/epoch contract, not on
the unrelated main receiver-history validity. Finally, G1 requires all four
child stages D0/T0/S0/R0 to succeed before exposing the reuse texture; a T0 or
S0 failure logs the four stage bits and retains deterministic reflection
instead of silently presenting raw D0 as a successful reused result.

Legacy black-noise parity, 2026-08-15
-------------------------------------

Runtime disproved the assumption that ordinary unbiased UPT D0/T0/S0 would
be sufficiently stable at half resolution.  The legacy reflection sampler's
actual contract is deliberately biased and much more aggressive:

* zero-target, malformed and occluded candidates never enter the reservoir
  and never increase M;
* initial RIS divides by the number of positive candidates rather than the
  fixed proposal schedule;
* an empty center steals the closest compatible positive spatial sample;
* incompatible or zero donors are skipped; the closest viable donor receives
  the one existing current-receiver visibility test;
* a successful rescue is allowed to donate again, filling sparse stochastic
  holes until fresh D0 coverage replaces it.

UPT47 now owns a separate `UPT47_REFLECTION_POSITIVE_ONLY` specialization in
all three child stages.  D0 restores the legacy positive-count convention and
does not stream visibility failures; the later energy correction retains that
admission policy while restoring the fixed-schedule denominator. T0 erases
count-only current records and
does not admit a shifted valid-zero history sample.  Empty-center S0 searches
the ordered immediate eight-pixel ring, re-evaluates each light at the current
receiver, then performs one visibility ray for the closest viable donor. A
non-empty center retains its original reservoir if a chosen
neighbor later fails normalization or visibility.

This bias is restricted to the private glass-reflection child artifact.  The
main unified DI/GI reservoir continues to count defined zero trials exactly as
required by its accepted estimator contract.  The change adds no full-buffer
clear and preserves the existing one-visibility-ray-per-pixel spatial ceiling.
The
full Vulkan release build and `spirv-val` for the new D0 plus specialized T0/S0
artifacts pass. The EXE and exactly those three reflection-only Vulkan blobs
were deployed. Deployed SHA-256 values are EXE
`A6176888DDD366440D4926FB5644AAE3F4F8A38E38B4158B76240EA4FEC1A6D4`,
D0 `9EC79CD5B043BF0B9EBFF14D2EDC8F9503DA327F6263A468914A28646F99FA19`,
T0 `1E493844ABE6CDA1BD2D8D7A72A03A7A6DEE24222B272236F156136E248F7BED`
and S0 `410D8FFCCFEC9D6B3661BFF5027054B97D315B8C4F26720319D12A10422DA175`.
Runtime quality and cost acceptance remain pending.

Motion floor and energy correction, 2026-08-15
----------------------------------------------

The legacy glass reflection did not own temporal/spatial reservoir pages. Its
motion-stable floor came from rebuilding eight analytic RIS candidates every
frame (`r_pathTracingReflectionSecondarySamples`, default 8), selecting one
shade and tracing at most one shadow ray. UPT47 had accidentally inherited the
global UPT emissive-trial default of one candidate, so camera motion exposed a
one-candidate D0 image while long T0 history hid it at rest.

The reflection child now uses the existing legacy reflection-sample cvar in
D0 and in T0/S0 source-PDF replay. Its admitted history M and age are capped at
4 rather than the main UPT defaults of 32, deliberately narrowing the quality
gap between rest and motion.

Positive-only admission is retained, but its added energy is compensated
explicitly. D0 computes the conditional positive estimate and multiplies it by
`positiveCandidateCount / candidateCount`, algebraically restoring the fixed
schedule denominator. Zero trials therefore affect energy but still never
become count-only black reservoirs. This is narrower than a post-resolve clamp
and propagates consistently through T0/S0 weights. Full Vulkan build and D0
`spirv-val` pass; deployed hashes are EXE
`C671F4E3BADD7C33596A0C315C41008B7892727FEA3007D6FE797465046F7ABC`
and reflection D0
`7080F6852A379E9F85A289D6B203AF90C6A364362ECA0689AFDF1034034BFCE4`.

Legacy emissive-path audit, 2026-08-15
--------------------------------------

`pathtrace_reflection_secondary.hlsli` confirms that legacy reflection did not
put emissive lights into its secondary NEE candidate set. It traced the sharp
reflection ray once, added exact emission at the terminal hit, and then ran
positive-only RIS over the Doom analytic-light array. UPT47 has the same
zero-noise emissive ownership: G1 evaluates and packs the reflected terminal's
emission into the compact48 receiver, and reflection R0 adds that receiver's
self-emission after resolving analytic DI. Therefore emissive RIS remains
excluded from the child; adding it would introduce precisely the stochastic
emissive noise the legacy path avoided.

Literal legacy D0 retry correction, 2026-08-15
----------------------------------------------

The motion-floor comparison disproved two conclusions above. With only the
analytic domain populated, ordinary UPT baseline scheduling already produced
eight proposals; routing `r_pathTracingReflectionSecondarySamples` through the
emissive-trial payload did not reduce the baseline to one. More importantly,
legacy did not accept an occluded selected RIS proposal as a black pixel.
`PathTraceReflectionSecondaryShade` retained up to four positive proposals,
tried the selected proposal first, and walked the retained alternatives until
one passed shade and visibility. UPT47 selected before visibility and had no
retry set, so a single occluded winner erased the reflection pixel even when
the same RIS draw contained usable lights. Motion across occluder boundaries
made that upstream loss dominate T0/S0.

The private reflection D0 artifact now reproduces the legacy estimator shape:

* the legacy sample cvar is authoritative for 1..16 analytic proposals;
* zero-target proposals never enter the retained set;
* at most four positive proposals are retained;
* the selected proposal is tried first and occlusion falls through to the
  other retained proposals;
* the published reservoir still contains exactly one visible sample; and
* mass is divided by positive proposal count, preserving legacy's intentional
  zero-conditioned energy bias rather than cancelling it back to the fixed
  schedule denominator.

This specialization can issue at most four D0 visibility rays, but only inside
the private glass-reflection child. The accepted main UPT D0 ceiling and
estimator remain unchanged. Full Vulkan release build and artifact validation
pass. The deployed reflection D0 SHA-256 is
`CF9CE9BAC4DBA1C3C0EDCC5F10B309CD7B9DCD499E7300A43BF47987C8ED5045`.
Runtime movement-quality and performance acceptance are pending.

Exact legacy producer isolation, 2026-08-15
-------------------------------------------

The literal estimator ports above did not change the live movement failure.
They still executed inside UPT's private D0/T0/S0/R0 child and therefore could
not prove whether the fault belonged to reflection sampling or to a later UPT
consumer.

`r_pathTracingUnifiedPtGlassLegacyOpticalDiagnostic 1` now exposes the actual
legacy view-16 optical producer already dispatched for UPT's front-pane
capture. In this mode:

* the HLSL `pathtrace_reflection_secondary.hlsli` result is authoritative;
* native Slang UPT46 optical transport is not dispatched;
* the private UPT47 D0/T0/S0/R0 child is not consumed;
* legacy transmission, reflection and distortion sidecars feed UPT45 directly;
* UPT45 explicitly decodes the legacy transmission alpha contract (attenuation
  in RGB, reflection energy in alpha 1..2) instead of confusing it with UPT46's
  resolved-refraction markers; and
* the main UPT P0/D0/T0/S0/R0 image and normal UPT presentation path remain in
  place.

Use the accepted UPT configuration, disable the private reflection child for a
clear comparison, then toggle only:

    r_pathTracingUnifiedPtGlassReflectionReuse 0
    r_pathTracingUnifiedPtGlassLegacyOpticalDiagnostic 0
    r_pathTracingUnifiedPtGlassLegacyOpticalDiagnostic 1

The console must report `requested/effective=1/1`,
`source=legacy-view16-sidecars`, `nativeUpt46=off` and `privateUpt47=off`.

Interpretation is deliberately narrow:

* if mode 1 restores the legacy motion behavior, the fault is in UPT46 or the
  UPT47 reflection child;
* if mode 1 still fails while clean-DI view 16 remains stable, the reflection
  producer is exonerated and the remaining difference is UPT45 composition,
  guide publication, DLSS-RR input, or later presentation; and
* this is not a claim that the whole legacy renderer runs inside UPT. It is the
  exact legacy optical producer routed through UPT so the producer/downstream
  boundary can be tested without changing UPT DI/GI.

The Vulkan release build passes, including `spirv-val` in the UPT45 build
rule. Only the executable and rebuilt UPT45 Vulkan blob are required for this
diagnostic. No DX12 shader is compiled.

Legacy analytic-domain adapter correction, 2026-08-15
-----------------------------------------------------

The first runtime attempt was not a valid legacy-source comparison: it showed
only direct terminal emissive hits, with analytic lighting and ordinary opaque
reflected surfaces black. The legacy shader and `t27` analytic-light buffer
were active, but the UPT adapter had left
`doomAnalyticFullCurrentCount`, `doomAnalyticLightInfo` and the associated
identity/previous/remap counts at zero. `PathTraceReflectionSecondaryShade`
therefore added exact terminal emission and returned before analytic RIS.

The UPT front-pane adapter now publishes the same full analytic count,
intensity, feature flags, identity counts, previous count and remap count used
by the real view-16 route. No shader or estimator changed. Re-run the same
diagnostic toggle; a valid mode-1 image must now contain analytically lit
opaque reflection hits as well as exact terminal emissive.

The Vulkan release build passes. This correction changes only the executable;
the previously deployed UPT45 blob remains current. Runtime movement-quality
comparison is pending.

Output-domain de-clustering experiment, 2026-08-15
-------------------------------------------------

The corrected exact-legacy source comparison isolated the visible difference:
legacy output is sparse but its noise remains one pixel wide, while the UPT47
child preserves more reflected detail but publishes spatially correlated
clusters. DLSS-RR tolerates the former as a weaker reflection and turns the
latter into enlarged structured artifacts under motion. Because the exact
legacy source passes through the same UPT45 and later presentation path, this
exonerates UPT45 transport composition as the origin of the clusters and makes
the private UPT47 reflection result the correct intervention boundary.

`r_pathTracingUnifiedPtGlassReflectionDecluster` adds an opt-in UPT45
presentation experiment without changing UPT47's estimator or history:

    0  consume every valid reused-reflection pixel (rollback/default)
    1  consume only frame-scrambled 3x3 local minima
    2  consume only frame-scrambled cardinal-neighbor local minima

Mode 1 is the primary test. A pixel is admitted only when its integer hash is
strictly lower than all eight touching neighbors, with screen index as a
deterministic tie break. Therefore two admitted pixels cannot touch, including
diagonally. Mode 2 is a denser A/B that excludes only side-adjacent admissions.
The election uses integer arithmetic only: it performs no neighboring texture
reads, traces no rays, allocates no buffers and adds no clears.

Rejected reuse does not make a black or invalid pixel. UPT45 falls back to the
existing deterministic UPT46 reflection at that pane pixel. Accepted reused
detail is pane-weighted exactly once and the identical contribution is written
to beauty and the DLSS-RR specular guide. This first test intentionally applies
no inverse-density compensation: amplifying the surviving samples would restore
mean energy at the cost of fireflies, defeating the diagnostic's purpose.

Required A/B under camera motion:

    r_pathTracingUnifiedPtGlassLegacyOpticalDiagnostic 0
    r_pathTracingUnifiedPtGlassReflectionReuse 1
    r_pathTracingUnifiedPtGlassReflectionDecluster 0
    r_pathTracingUnifiedPtGlassReflectionDecluster 1

The console must report `requested/effective=1/1`,
`pattern=3x3-local-min`, `fallback=UPT46`, `extraRays=0`,
`neighborReads=0`, `buffers=0`, `clears=0` and `compensation=none`.
Acceptance is disappearance of multi-pixel/structured reflection noise under
motion without black holes, transmission changes, pane-edge corruption or a
beauty/specular-guide mismatch. Reflection weakening is expected and should be
judged against the proven legacy sparse-output tolerance. Mode 2 is useful only
if mode 1 is stable but unnecessarily weak.

The Vulkan release build passes and includes SPIR-V validation. The change
reuses the existing 32-byte UPT45 push-constant ABI by packing source mode,
de-cluster mode and frame sample index into one uint. Only the executable and
rebuilt UPT45 Vulkan blob require deployment. Runtime A/B is pending.

De-cluster ownership correction, 2026-08-15
-------------------------------------------

Runtime mode 1 is substantially more compatible with DLSS-RR: legacy retains
a small motion advantage, while UPT47 resolves more reflection detail after RR
has time to accumulate. The important remaining loss was exact reflected
emission. UPT47 R0 contains the reflected receiver's packed self-emission, so
UPT45's local-minimum admission unintentionally thinned the dominant zero-noise
emissive term along with stochastic analytic lighting.

UPT46 now evaluates exact terminal emission during its single reflected hit and
includes it in the deterministic fallback while passing the same evaluated
value into the compact reflected receiver. Consequently:

* an admitted pixel obtains self-emission from UPT47 R0 exactly once;
* a rejected pixel obtains the same terminal emission from UPT46 exactly once;
* only the reused analytic/detail remainder is effectively de-clustered; and
* there is no emissive RIS, additional ray, duplicate texture evaluation or
  inverse-density compensation.

The same audit found that UPT46 had also admitted every non-glass surface with
roughness at or below 0.011 as an `exactMirror`. That was not glass transport:
it replaced the already resolved main-UPT opaque material with UPT46's flat
one-ray mini shade. UPT46 now returns immediately for every non-transmitting
surface. Opaque zero-roughness reflection, history and DLSS-RR guide ownership
are restored entirely to the main UPT path. UPT45 retains its historical exact
mirror decoder only as an inert compatibility path; native UPT46 no longer
publishes that marker.

The Vulkan release build and both UPT46 SPIR-V variants validate. Runtime checks
must confirm full-power reflected emissive panels with de-cluster mode 1 and
pre-glass behavior for opaque zero-roughness surfaces. Transmission and actual
glass reflection behavior must remain unchanged.
