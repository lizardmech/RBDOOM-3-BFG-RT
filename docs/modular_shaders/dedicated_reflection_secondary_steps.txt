Purpose
-------

This document is a worker handoff for a dedicated reflection secondary service
in the clean RTXDI DI view-16 route (and, later, opaque high-gloss materials).

Shipping titles (RTX Remix-style remasters, Cyberpunk-class RT reflections)
generally do **not** rely on generic ReSTIR-PT / full-frame reservoir output
for Dirac glass and near-mirror metals. They:

    1. Trace one (or few) reflection ray(s) from the primary surface.
    2. Shade the hit with a **simplified lighting model**.
    3. Composite by Fresnel / specular lobe weight.

Simplified shade typically **includes** direct lights and important emissives,
and **skips** expensive features that barely matter in a mirror: multi-bounce
GI, volumetrics, nested full PT, heavy ReSTIR on the reflection hit.

The target is not "run clean DI twice." The target is a first-class reflection
secondary pass shared by:

    - clear glass (Dirac / thin-wall Fresnel; upgrade of Option B shade)
    - high-gloss opaque (low roughness GGX / near-mirror)

Read this document before editing code. Do not reopen the RTX Remix tree unless
local code contradicts this guide. Prefer reusing local transport already in
cleanroom_rtxdi (TraceReflectionPsrHit, ShadeReflectionHit) over new
integrations.


Priority Rule (mandatory)
-------------------------

Quality of the **reflection ray + simplified shade** first. Do not expand
scope into dirt, full OpenPBR productization, or mid-roughness metals until
glass Dirac secondary is clearly better than the current hybrid.

    Phase 0 — extract and contract (do first):
        pull Trace + Shade into a shared reflection-secondary API
        define inputs/outputs/flags
        glass still the only caller
        no behavior change required beyond extract

    Phase 1 — glass dedicated ray quality:
        upgrade simplified shade (more lights, emissives, optional shadows)
        glass beauty uses this radiance path intentionally
        keep Phase A RR guide policy (do not re-litigate dirt/glass coatings)
        validation: PSR alone looks as good or better than Option B, less noise

    Phase 2 — opaque high-gloss eligibility:
        roughness / alpha threshold
        one secondary sample per pixel (mirror or VNDF)
        composite into view-16 beauty without replacing primary for RR

    Phase 3 — GGX VNDF sampling for non-Dirac gloss:
        sample direction with GGX Smith VNDF (see openpbr_eon_ggx_vndf_steps)
        same simplified shade at hit
        still not full ReSTIR-PT on the reflection hit

    Phase 4 — optional polish (only after 1–3):
        1 cheap diffuse bounce at hit (probe/cache)
        nested mirror bounce cap 1–2
        temporal/spatial reuse of secondary radiance (not full reservoirs)

If a task improves mid-roughness metals, volumetrics-in-mirror, or dirt overlays
but does not improve Dirac/high-gloss reflection quality, it does not belong
here.


Core Decision
-------------

Keep three jobs separate (shipping titles do this; do not merge them):

    ReSTIR DI / clean DI
        Who lights the world we see as primary (noisy, reservoir-based).

    Reflection secondary (this document)
        What does this mirror / high-gloss lobe see, cheaply.

    PSR / G-buffers / RR guides
        What surface identity does this pixel have for DLSS-RR.

Glass already uses a hybrid that proves the beauty model:

    beauty ≈ T * DI(behind) + R * ShadeMirror(simplified)

Reflection secondary owns and improves `ShadeMirror`. It does **not** replace
transmission PSR, and it does **not** require reflection PSR to own every
pixel's primary surface.

Do not confuse:

    Reflection PSR
        Optional surface replacement for DI/RR identity when the reflection
        lane owns the pixel. In Remix, this is the **main** noiseless path:
        the reflected hit becomes primary and receives clean DI / RTXDI once.
        That is intentional primary lighting, not "run DI twice."

    Reflection secondary / Option B shade
        Already-shaded reflected radiance from a simplified hit path (hybrid
        R when T owns, or when secondary is kept). Promote quality via RIS,
        not multi-SPP. See research subsection.

    Full clean DI reservoirs as a second pass on every reflection hit
        Wrong default "quality" plan when the hit is *not* primary-selected:
        second DI frame of noise/cost, and Remix avoids RTXDI on secondary
        for spatial mismatch. Do not build this.


Non-Goals (this lane)
---------------------

Do not build any of these as acceptance requirements for Phase 0–1:

    - full multi-bounce GI inside the reflection hit
    - volumetrics / fog / participating media in the reflection ray
    - running full clean DI reservoirs on every reflection hit
    - generic mid-roughness metal productization
    - screen-space reflections as the primary solution
    - dirt/grime glass overlays (Phase B of basic_glass_psr_reflection_steps)
    - dual-surface DLSS-RR product support for opaque gloss
    - frosted multi-sample glass transmission
    - reopening Remix source as the implementation base

Phase 2–3 may touch GGX VNDF. Phase 4 may touch cheap probes. Full path-trace
parity inside mirrors is out of scope indefinitely unless product priority
changes.

Mental Model
------------

Primary frame (simplified):

    Primary (opaque / glass base)
        │
        ├─ clean DI / ReSTIR
        │       diffuse + rough specular energy (noisy, reservoir)
        │
        └─ Reflection Secondary
                Trace 1 ray (Dirac or low-α GGX sample)
                Shade simplified lighting
                Write radiance + hitT (+ optional material for RR)
                Composite by Fresnel / lobe weight

Glass-specific beauty (target contract):

    1. Transmission PSR publishes behind-glass primary for DI when T-owned.
    2. Reflection secondary always available when glass has non-zero R.
    3. Beauty = T * DI(behind) + R * secondaryRadiance
       (R-owned DI of mirror is optional; do not double-count with secondary).
    4. RR guides keep Phase A clear-glass policy unless product revisits it.

Opaque high-gloss beauty (target contract):

    1. Primary surface stays the metal/glossy material (RR identity).
    2. Secondary samples specular direction (mirror or VNDF).
    3. Beauty = DI_base + secondaryRadiance * specularWeight.
    4. Specular hit distance = secondary ray length when secondary fires.


What Shipping Games Imply
-------------------------

Comparative / design constraints (not a license to copy proprietary code):

    - Dirac and near-mirror reflections are a **specialized ray budget**, not
      a free sample from the full PT/ReSTIR pipeline.
    - Shade at the reflection hit is often **direct + emissive**, not full GI.
    - Features that barely change mirror appearance (volumetrics, multi-bounce
      diffuse GI, complex SSS) are omitted or approximated.
    - DLSS-RR gets clean material guides for the **primary** (or glass policy
      surface), plus specular hit distance for the reflection ray length.
    - Noisy ReSTIR-only reflection on glass is a known weak match for RR;
      dedicated secondary + stable guides is the shipping shape.

Local capture notes from Phase A still apply for glass guides. Do not regress
them while upgrading secondary shade.

must treat that subsection as binding quality direction for Phase 1+.


RTX Remix Research Findings (binding agent direction)
-----------------------------------------------------

Source: local tree E:\prog\references\dxvk-remix-git (shaders under
src/dxvk/shaders/rtx/, options in rtx_options.h). This is comparative
architecture research only — do not copy proprietary code; implement with
local cleanroom_rtxdi APIs. Do not re-open the Remix tree unless local

### Finding 1 — Near-noiseless glass/mirror is PSR + primary DI, not more SPP

Remix does **not** get clean glass reflections by averaging many simplified
secondary light samples. For Dirac specular (Portal-style glass reflection,
perfect mirrors):

    1. On the first hit, if the specular lobe is Dirac, fire **one** perfect
       reflection ray (Reflection PSR / PSRR).
    2. **Replace the primary G-buffer surface** with the hit through that
       ray (Fresnel / thin-wall series stored as attenuation).
    3. Run **full primary Integrate Direct (RTXDI)** on the promoted surface
       as if it were the primary wall/floor the mirror "sees."

That is why DI can look near noiseless at **1 SPP** on ordinary surfaces and
also on what the mirror shows: the reflection hit **is** the primary for
lighting. Quality comes from **reservoir DI on a promoted surface**, not from
multi-SPP Monte Carlo of a cheap shade.

Local parallel:

    - CLEAN_FLAG_GLASS_REFLECTION_PSR / TraceReflectionPsrHit already exist.
    - When R owns (or should own) the pixel, prefer identity + clean DI over
      pumping PathTraceReflectionSecondaryShade sample counts.
    - Hybrid T * DI(behind) + R * secondary remains valid when T-owned; still
      do not "fix" R noise with 4–8 independent draws as the quality plan.

Opaque PSR in Remix only fires when: Dirac specular, **no** diffuse lobe,
not emissive. Rough GGX is **not** promoted via PSR — it goes through normal
indirect / denoise. Match that policy in Phase 2–3.

### Finding 2 — Secondary hits use RIS (one sample), never full RTXDI

When the reflection hit is **not** the selected primary integration surface
(e.g. glass stochastic R vs T pick lands on transmission as primary), Remix
still lights the secondary surface with **direct NEE**, but:

    - Primary selected surface  -> RTXDI reservoirs (spatiotemporal).
    - Secondary / non-primary   -> **RIS only** (or NEE cache), not full DI.

Explicit integrator reason (paraphrased from integrate direct): running RTXDI
on secondary tries to use lights chosen for the **primary pixel location** and
looks wrong when the hit is far away in space.

RIS shape (rtx.risLightSampleCount default **7**):

    - Consider M candidate lights from the global pool (strided / typed ranges).
    - Weighted reservoir selection (target pdf from light weight at surface).
    - **One** final light area sample + **one** visibility evaluation.
    - Not: N independent uniform light picks averaged together.

Indirect bounces use the same idea: RIS or NEE cache, optional ReSTIR GI later,
then NRD / DLSS-RR. Residual noise is a **denoise / temporal** problem, not a
"raise reflection SPP" problem.

### Finding 3 — Multi-SPP average of simplified shade is the wrong lever

Local Step 1a landed:

    r_pathTracingReflectionSecondarySamples (1–8, default 4)
    PathTraceReflectionSecondaryShade: N independent uniform analytic draws,
    average the estimates.

That is unbiased multi-SPP MC. It is a **bootstrap**, not the shipping quality
model. It will not converge like primary DI because it lacks:

    - spatiotemporal light reservoirs
    - importance sampling among lights (beyond uniform)
    - denoise-oriented signal packing

**Mandatory anti-pattern for agents:**

    DO NOT raise secondary sample count (default 4 -> 8, etc.) as the
    quality fix for sparkly / noisy glass reflections.
    DO NOT invent a full second ReSTIR-DI / ReSTIR-PT pass on every mirror hit.
    DO NOT treat "more samples" as done for Phase 1.

### Agent direction — how to get Remix-class results locally

Priority order (do higher items before lower):

    A. Dirac glass / R-owned quality (true shipping path)
        Prefer reflection PSR so the reflected hit is the DI primary when R
        owns the pixel. That reuses the already near-noiseless clean DI path
        (view-16 RTXDI). Compose carefully (Step 2 no double-count): either
        DI-only on R-owned or secondary-only, never both for the same energy.

    B. Hybrid R * secondary shade (T-owned glass, or when secondary is kept)
        Replace multi-SPP uniform average with **RIS-style light selection**:
            M candidates (start ~7, cvar-tunable)
            target pdf ~ luminance * area proxy * n·l (and later MIS)
            select ONE light, shade once, optional ONE shadow ray
        Include hit emissive as noise-free add (already partial).
        Keep denylist: no volumetrics, no nested full GI, no reservoir DI on
        the secondary hit.

    C. Opaque high-gloss (Phase 2–3)
        One mirror or GGX VNDF ray; same RIS shade at hit.
        Do not PSR-replace primary for RR identity (primary stays metal).
        Residual noise: denoise + specular hitT, not multi-SPP.

    D. Phase 4 only after A–C
        Cheap probe / 1 diffuse bounce at hit, nested mirror cap 1–2,
        optional temporal reuse of secondary radiance (not full reservoirs).

Equal-cost validation rule for shade work:

    Compare RIS-M=7 (1 shade + 1 shadow) vs multi-SPP-N=4/8 at **equal
    shadow-ray budget**. Accept RIS if variance is lower or equal at same cost.
    Multi-SPP may remain as a debug / A-B cvar; it must not be the default
    quality path once RIS lands.

### Map: Remix concept -> local piece

    Remix Reflection PSR (PSRR)
        -> glass reflection PSR flags + TraceReflectionPsrHit / secondary
           Trace; promote surface into DI when R-owned (Step 2 contract).

    Remix primary Integrate Direct + RTXDI
        -> existing clean DI view-16 on primary / PSR-resolved surface.
           Do not reimplement.

    Remix secondary NEE via RIS (M candidates, 1 sample)
        -> upgrade PathTraceReflectionSecondaryShade (Step 1 / 1b).
           Target for hybrid secondary path.

    Remix NEE cache / ReSTIR GI / NRD
        -> Phase 4 optional or existing denoise/RR pipeline; not Phase 1
           acceptance.

    Remix: no full ReSTIR on secondary
        -> Non-goal already listed; keep it.

### What "done" looks like for Phase 1 after this research

    - Glass Dirac reflections lean on PSR + DI quality where R owns the pixel,
      OR on RIS-1 secondary when hybrid R is used — not on sampleCount=8.
    - Default secondary shade is RIS (or equivalent importance selection),
      with multi-SPP only as optional debug.
    - Documented no double-count between reflection PSR DI and secondary.
    - Noise on lights in mirrors is "soft" like primary DI class, not sparkly
      single-light lottery; emissives on hit stay direct and stable.

If an implementation plan's main lever is "increase secondary samples," reject
it and re-plan against A then B above.

Reference Architecture Summary
------------------------------

Shipping shape (Remix / high-end RT reflection class) — refined by research:

    Dirac glass / mirror:
        material says lobe is Dirac
        emit **one** reflection ray
        **promote hit to primary G-buffer** (PSR) when that lobe owns the pixel
        light with **full primary DI / RTXDI** (1 spp class quality)
        composite Fresnel attenuation into beauty / throughput
        RR: primary (or glass policy) guides + specular hit distance

    Secondary / hybrid (hit not primary-selected):
        same one reflection ray
        shade hit with **RIS direct NEE** (M candidates -> 1 light + 1 shadow)
        + hit emissive; no full ReSTIR on secondary
        residual: denoise / temporal, not multi-SPP

    High-gloss non-Dirac:
        VNDF or similar sample; same simplified/RIS shade; not PSR primary

For rbdoom minimum equivalent:

    shared TraceReflectionSecondary(origin, dir, ignore, maxT) -> hit
    shared ShadeReflectionSecondary(hit, budget flags) -> radiance
        Phase 1 target: RIS selection, not multi-SPP average (Step 1a is
        bootstrap only; see research subsection)
    glass caller: dir = reflect, weight = glass R
    opaque caller: dir = mirror or VNDF, weight = specular lobe weight
    compose: no double-count with DI when DI already owns the mirror surface
    hitT written for RR specular hit distance when secondary contributes
    R-owned glass: prefer PSR surface + clean DI when product allows


Shade Budget Ladder
-------------------

    v0 (current Option B / ShadeReflectionHit)
        1 mirror ray
        1 analytic / domain light sample + hit emissive
        no shadows required
        glass only

    v1a (landed bootstrap — not the quality end state)
        multi-sample uniform analytic draws averaged (default 4)
        optional shadows
        keep for A/B / debug; do not raise default as Phase 1 "done"

    v1 (Phase 1 target — match Remix secondary NEE)
        same transport (1 reflection ray)
        RIS: M candidate lights (start ~7) -> **one** selected sample
        optional **one** visibility ray on the selected light
        hit emissive direct; analytics + later larger light classes
        simple MIS optional
        hit material: Lambertian + simple specular OR albedo + emissive
        still no multi-bounce GI, no volumetrics, no full reservoir DI

    v1+ (R-owned glass quality)
        when reflection owns the pixel: PSR primary + clean DI instead of
        (or instead of only) secondary multi-sample shade

    v2 (Phase 2–3)
        GGX VNDF sample for non-Dirac high gloss
        same v1 RIS shade
        1 direction sample + optional temporal reuse later

    v3 (Phase 4, optional)
        1 cheap diffuse bounce at hit (probe/cache)
        nested mirror bounce cap 1–2


Glass vs Opaque Policy (same service, different ownership)
----------------------------------------------------------

Glass (clear):

    Direction: perfect reflect (normal-map bend later if needed)
    Energy: thin-glass Fresnel R (existing glass math)
    RR: keep Phase A clear-glass policy
        behind depth/normals, blend albedo/spec, hitT = mirror length
    Beauty: T * DI(behind) + R * secondary
    Do not require reflection PSR primary for secondary to fire

Opaque high-gloss:

    Direction: mirror if roughness ~ 0, else GGX VNDF
    Energy: Fresnel / specular weight
    RR: primary stays the metal/glossy surface
    Beauty: DI + secondary * weight
    Do not replace primary with mirror hit for mid-gloss (fights RR)

Step 4: Eligibility and Composite
---------------------------------

Type: material / compose

    - Do not clear motion vectors from glass PSR (primary motion stands).
    - Keep defaults: GlassReflectionPsr 1, GlassReflection 0 unless product
      changes them again.
    - Dirt/grime remains Phase B of basic_glass_psr_reflection_steps.txt.
